Basic infomation/intro

Introduction

Currently building a personal project that includes a frontend, backend, database, and connects to local LLMs on the users pc

Will have 3 main features, a personal assistant (scheduling, recipes, etc) that will store your info in a rag database (i think thats what it is called)

It will have a coding agent, that will be linked to its own repository so that it can continue building your application. Also: roleplay ai with comfyui image generation abilities

Use Cases

  1. Coding, will be able to just describe what you want, itll give you the status and explain its decisions
  2. roleplay with image generation via comfyui(self explanatory)
  3. personal assitant, will have persistent storage so it can keep track of stuff you mention (commonly used recipes), and will be able to search the internet

Features

Planned features

Frontend dashboard, with full mode switching, wiki, installation guide, etc

database to store agent context

3 models, agentic coding, themed roleplay (search internet for personality maybe)

ability to let all 3 modles use nodes to communicate or update tools (coder, roleplay, and assistant can use comfyui)
